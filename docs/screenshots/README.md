# Screenshots

Drop PNGs here matching these filenames — they're referenced by `../README.md`:

| File | What it should show |
|---|---|
| `study.png` | A study card mid-session (question + Reveal button or a card just revealed with the rate buttons). iPad portrait or a wide desktop view, 1000–1400px wide. |
| `reading.png` | The Reading tab with the TOC sidebar visible on the left and a concept-fix sheet rendered on the right. Pick a sheet with a table or "For the exam" callout for visual interest. |
| `welcome.png` | The welcome dialog at first launch — greeting, exam countdown, and the Today's plan task list. Best with the exam date set so the countdown shows. |

Tips:
- iPad: `Top + Volume Up` (or `Cmd+Shift+4` on a Mac with Continuity).
- Crop tight; don't include the OS chrome.
- Same theme across all three (auto/dark looks the slickest; pick one and stick with it).
- ≤ ~250 KB each so the README stays light.

The README's `<img>` tags pick them up automatically — no further wiring needed.
